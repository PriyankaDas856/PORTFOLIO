# Design Systems for Startups: Start Small, Scale Smart

When I joined my first startup internship, the codebase had 47 shades of grey and 12 different button styles. Sound familiar?

## Phase 1: Tokens First

Before components, define your design tokens:

- **Colors**: 1 background, 1 text, 1 accent. That's it.
- **Spacing**: 4px base unit. Use multiples.
- **Typography**: 2 fonts max. 3-4 sizes.

## Phase 2: Core Components

Build only what you use daily:

1. Button (3 variants)
2. Input
3. Card
4. Typography components

## Phase 3: Document as You Go

Storybook is great but Notion works too. The key is consistency, not tooling.

## When to Invest More

Upgrade your system when:

- 3+ developers touch the UI weekly
- You're rebuilding the same component for the 3rd time
- Design-dev handoff takes more than a day

Start small. Scale when it hurts not to.
