# From Idea to MVP in 4 Weeks

Speed doesn't mean sloppiness. Here's the framework I use to go from idea to working product in one month.

## Week 1: Discover

- 5+ user interviews
- Problem statement document
- Competitive analysis
- Success metrics defined

## Week 2: Design

- User flows mapped
- Lo-fi wireframes
- Key screens in Figma
- Design review with 2+ people

## Week 3: Build

- Core feature only (cut everything else)
- Daily commits
- Test on real devices
- Deploy to staging

## Week 4: Ship & Learn

- Beta with 10 users
- Collect feedback
- Fix critical issues
- Launch publicly

## The Non-Negotiables

Even in 4 weeks, never skip:

- Basic accessibility
- Error handling
- Mobile responsiveness
- One analytics event

Quality is a habit, not a phase.
